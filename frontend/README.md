# CarePoint frontend

React + Vite client for the Healthcare Dispensary Management System.

## Run
1. `npm install`
2. Copy `.env.example` to `.env` (default API URL: `http://localhost:5000/api`).
3. `npm run dev`
4. Open `http://localhost:5173`.

The Express backend must be running on port 5000 and connected to the existing `dispensary_db` MySQL database.
